ABOUT PIKBOT

Research, not promises

The existing engine uses weighted recent results, a simple normal approximation, minimum history thresholds and candidate enumeration. The probabilities are uncalibrated and should not be interpreted as a validated winning edge.

The sports category selector filters displayed results; it does not create missing sports data. Live sportsbook lines and automated entry placement are not enabled.

Install on iPhone

Open the hosted HTTPS site in Safari, choose Share, then Add to Home Screen. Predictions still require the backend online.
